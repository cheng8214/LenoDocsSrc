示例程序导览（examples 目录怎么逛）

仓库的 examples/ 里有 800 多个 .leno 文件，但不需要全看——大半是回归测试（test_*） 和性能基准（bench_* / *性能测试*），对学习者没价值，混在一起反而劝退。

这篇挑出 26 个"看得懂、跑得通、有收获"的示例，按主题排好，每个都实测过 （能编译 + 能跑完，退出码 0）。

怎么跑

在仓库根目录（examples/ 的上一级）执行：

leno examples\for\for.leno

只想确认它能编译（不运行）：

leno --check examples\for\for.leno

文件名里有空格或中文时加引号：leno "examples\for\for.leno" 一般不用， 但 leno "examples\try catch\try catch finally.leno" 这种必须加。

一、先把语法看熟（6 个）

文件 一句话
examples/for/for.leno for a:b to i 数数循环（闭区间，两头都算）
examples/if/if.leno if / else 最朴素的分支
examples/if/if eif.leno else if 与 eif（等价写法）
examples/三元运算符/三元运算符.leno if 条件 then a else b —— 一行内做选择
examples/插值/插值.leno $"{变量}" 字符串插值（最短的一个例子，6 行）
examples/多变量声明/多变量声明.leno var a=1, b, c=2 / int x, y, z

二、函数与闭包（4 个）

文件 一句话
examples/func/func.leno 定义函数、传参、return（注意函数可以写在 main 后面）
examples/func/func 闭包.leno 闭包最朴素的形态
examples/闭包/多层闭包.leno 函数返回函数，逐层捕获外层变量
examples/多返回值/min_multi.leno func f(): [int, int] + var[int,int](a,b) = f()

三、数组与排序（2 个）

文件 一句话
examples/数组切片/简单的切片.leno 切片是闭区间：a[2:5] 含 2 和 5
examples/排序测试/冒泡排序.leno 手写排序（想理解 sort() 在做什么就看这个）

四、枚举（2 个）

文件 一句话
examples/enum/test_simple.leno 最基础的 int 枚举 + 取值
examples/enum/cs.leno 用枚举表达状态（比魔法数字清楚）

五、错误处理（2 个）

文件 一句话
examples/try catch/try catch finally.leno try / catch / finally 三者顺序
examples/try catch/异常传播.leno 异常怎么从内层函数传到外层 catch

文件 一句话
examples/threads/pool.leno 20 个任务分给若干 worker，带期望值断言（跑完打印"失败 0"）
examples/async await/test_async_simple.leno 最小 async / await 例子

examples/clib/test_min.leno clib 声明式调用（不用手写 FFI 绑定）

八、能直接用的工具（2 个）

文件 一句话

九、JSON 与大数（3 个）

文件 一句话
examples/jsons/复杂json解析.leno 嵌套 JSON 的解析与取值（唐诗数据集）

哪些不用看

前缀 / 关键词 为什么跳过
test_*.leno 回归测试，很多是"故意写错看报错"
bench_* / *性能测试* / 性能测试/ 目录 压测脚本，跑得久、代码不好看
dict_bug_repro/、改进测试/ 历史 bug 复现，看懂需要背景知识
minilang/ 一个玩具解释器，属于"炫技"，不是入门材料

看完示例之后

示例是"读"的，接下来该"写"了：

  1. 抄 常见任务cookbook.md 里最像你需求的那一段，改成自己的；
  2. 用 安装与第一个项目.md 里的 leno --init 建个项目，把代码搬进去；
  3. 写错了查 语言陷阱速查.md，不确定某个函数签名查 module_*.md。

本文的链接都是仓库路径（指向 gitee 的 examples/），不在本站点内。 列出的 26 个文件全部实测：--check 通过 + 实际运行退出码 0。
