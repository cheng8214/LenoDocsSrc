扩展模块总览

这一节收录的是独立的扩展模块包，位于 Leno/build/leno_module/，与语言内置标准库（strings / files / ffi 那 19 个）不是一回事。 内置标准库见上一节「模块 API 参考」；这里是按需 import 的扩展包：压缩、加密、HTTP、SQLite、SDL3、Web、Excel、二维码……

⚠ 包名 ≠ import 名

import "X" 里的 X 是 lib/ 下的入口文件名（不含 .leno），不是 leno.toml 的 [package] name。照包名写会报「找不到模块」。最容易错的：

包名 正确 import 错写
LenoFS import "FS" import "LenoFS"
LenoSqlite import "sqlite3" import "LenoSqlite"
LenoHack import "GameHelper" import "LenoHack"
LenoMusic import "Music" import "LenoMusic"
LenoWeb import "WebNet" / "WebHtml" / "WebCrawl" / "Web" import "LenoWeb"

LenoWeb 的四个入口

LenoWeb 拆成四个按需入口，选最轻的：

入口 依赖规模 冷缓存编译 用在
import "WebNet" core + net = 2256 行 31 ms 只要 HTTP 客户端（最常用）
import "WebHtml" html + charset + gzip = 2650 行 32 ms 解析 HTML / CSS 选择器
import "WebCrawl" crawler + net + core = 3841 行 56 ms URL 工具 / robots / sitemap / 爬虫骨架
import "Web" 全都有 + cdp + ws = 8510 行 59 ms CDP 无头浏览器 / WebSocket

三个窄入口各自覆盖 web_net 的全部 54 个导出；WebNet → Web 的迁移是纯增量，不用改调用点。

⚠ web_net.leno / web_html.leno / web_crawler.leno 是内部文件，不要直接 import。

模块测试

:: 全部模块（缺原生库的自动 SKIP）
build\leno.exe build\leno_module\run_all_tests.leno

:: 只跑指定模块
build\leno.exe build\leno_module\run_all_tests.leno --only LenoCSV,LenoZip

模块断言放在各自 test/ 下，不进语言的 assert/ —— 后者要求零原生依赖，是「语言是否健康」的干净信号。
