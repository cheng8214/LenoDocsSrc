Leno Dicts 模块

本文档详细说明 dicts 模块提供的字典（哈希表）操作功能。

概述

Dicts 模块是 Leno 语言中用于字典（键值对存储）操作的核心模块。字典使用字符串作为键，可以存储任意类型的值。

特性

  • 字符串键：键必须是字符串类型
  • 任意值：值可以是任意类型（数字、字符串、数组、字典等）
  • 动态扩容：自动处理容量增长
  • 哈希实现：基于哈希表，平均 O(1) 访问速度
  • 双模式调用：实例方法或模块方法

返回类型（跟接收者一致）

keys() 返回 Array[K]、values() 返回 Array[V]，其中 K / V = 接收者 Dict[K, V] 的类型参数 （声明式规格 NTYPE_ARG0_KEY / NTYPE_ARG0_VALUE，编译器在调用点用接收者的实际类型解析 ⇒ 调用点零收窄）：

Dict[string, int] m = {"a": 1, "b": 2}
Array[string] ks = m.keys()      // 元素类型就是 string
Array[int]    vs = m.values()    // 元素类型就是 int（可直接参与运算）

⚠ get(k[, default]) 故意不在此列：它的类型由默认值实参推出来 —— get("x", 0) → int、 get("y", 0.0) → float、get("z", false) → bool（见 assert/test_dict_get_infer.leno）。 那是另一条更精确的规则；把 get 标成"返回 V"会盖掉它（实测会让 4 个用例退化成 any）。 无默认值时（get(k)）返回 any。

使用方式

字典的方法只有实例方法这一种形式（d.len() / d.set(k, v) …）：

var dict = {"name": "Alice", "age": 25}
print(dict.len())
dict.set("city", "Beijing")

⚠ 订正（2026-10-14）：本节此前还列了一条"方式2：模块方法"（import dicts + dicts.len(dict)）—— 实测不成立 ✗：dicts 根本不是可导入的原生模块，写 import dicts 直接报「未知的原生模块 'dicts'」（可用列表里没有它：io / times / arrays / strings / maths / rands / files / asyncs / dirs / jsons / sockets / ffi / threads / regexs / types / sys ✓）。 有模块形式的是数组（arrays.len(arr) / arrays.copy(arr) ✓）；字典没有 —— 下面「实例方法 vs 模块方法」那张对照表已按实情订正 ✓。

核心方法

len()

返回字典中键值对的数量。

参数: 无
返回: int - 键值对数量

var dict = {"a": 1, "b": 2, "c": 3}
print(dict.len())  // 3

// 空字典
var empty = {}
print(empty.len())  // 0

has(key)

检查字典是否包含指定键。

参数: - key (string): 要检查的键

返回: bool - 是否包含该键

var dict = {"name": "Alice", "age": 25}
print(dict.has("name"))   // true
print(dict.has("email"))  // false

// 嵌套检查
var nested = {"user": {"name": "Bob"}}
print(nested.has("user"))        // true
// 注意：has 不检查嵌套键
// print(nested.has("user.name")) // false

get(key) / get(key, default)

获取指定键的值。

参数: - key (string): 要获取的键 - default (可选): 键不存在时的默认值

返回: - 无默认值时返回 any，键不存在返回 null - 带默认值时，返回类型由默认值类型推断：

默认值类型 推断返回类型 示例
0 (int) int opts.get("x", 0)
0.0 (float) float opts.get("y", 0.0)
true/false (bool) bool opts.get("z", false)
"" (string) string opts.get("name", "") 
var dict = {"name": "Alice", "age": 25}

// 无默认值：返回 any
print(dict.get("name"))   // Alice
print(dict.get("email"))  // null

// 带默认值：返回类型由默认值推断
int age = dict.get("age", 0)         // 返回 int，无需 _int() 转换
string name = dict.get("name", "")   // 返回 string，无需 _str() 转换
int missing = dict.get("email", -1)  // 键不存在，返回默认值 -1（int）

// int → float 自动提升
float f = dict.get("age", 0)   // int 默认值自动提升为 float

// float → int 不允许（会截断小数）
// int x = dict.get("score", 0.0)  // 编译报错：float 不能自动降级为 int

// 使用 [] 语法等价
print(dict["name"])       // Alice

set(key, value)

设置键值对。如果键已存在则更新值，不存在则添加。

参数: - key (string): 键 - value (any): 值

返回: null

var dict = {}

// 添加新键值对
dict.set("name", "Alice")
dict.set("age", 25)
print(dict)  // {name: Alice, age: 25}

// 更新已有键
dict.set("age", 26)
print(dict)  // {name: Alice, age: 26}

// 使用 [] 语法等价
dict["city"] = "Beijing"
print(dict)  // {name: Alice, age: 26, city: Beijing}

remove(key)

删除指定键值对，返回被删掉的值。

参数: - key (string): 要删除的键

返回: 被删除的值；键不存在（或值本身就是 null）⇒ null

★ 2026-10-24 起返回被删的值（此前一律返回 null）—— 与 array.remove(i) 返回被删元素的口径对齐，也让"取出即删"一步完成 ✓ 静态类型是 any（键可能不存在 ⇒ 不能承诺 V），需要具体类型时用 _int() / _str() 收窄， 与 get(key) 同一口径。 d.remove("a") 与 d.remove("zz") 都返回 null ⇒ 想区分"删掉了空值"和"键本来就没有"， 先调 has(key)。

var dict = {"a": 1, "b": 2, "c": 3}

var old = dict.remove("b")     // old == 2（被删掉的值）
print(dict)                    // {a: 1, c: 3}

// 删除不存在的键（不报错，返回 null）
var none = dict.remove("z")    // none == null
print(dict)                    // {a: 1, c: 3}

// 键存在但值是 null：返回 null，但确实删掉了 —— 想区分就先 has()
var n = {"k": null}
print(n.has("k"))              // true
n.remove("k")
print(n.has("k"))              // false

setdefault(key, default)

键存在 ⇒ 返回现有值（不覆盖）；键不存在 ⇒ 写入 default 并返回它 ✓ （与 Python 的 dict.setdefault 同语义 ✓）

参数: - key (any): 键 - default (any): 键不存在时要写入并返回的值

返回: any - 键对应的值（已有的，或刚写入的 default）

var counts = {"a": 1}
print(counts.setdefault("a", 99))   // 1      （已存在 ⇒ **不覆盖** ✓）
print(counts.setdefault("b", 7))    // 7      （不存在 ⇒ 写入并返回 ✓）
print(counts.get("b"))              // 7      （确实写进去了 ✓）

// 典型用法：分组/计数（省掉"先 has 再 set"两步 ✓）
var groups = {}
var ks = ["x", "y", "x", "z", "x"]
for ks to k {
    groups.setdefault(k, 0)
    groups.set(k, _int(groups.get(k)) + 1)
}
print(groups.get("x"))              // 3

遍历方法

keys()

获取所有键的数组。

参数: 无
返回: Array - 键的数组

var dict = {"name": "Alice", "age": 25, "city": "Beijing"}
var keys = dict.keys()
print(keys)  // [name, age, city]

// 遍历键
for keys to key {
    print("键: " + key)
}

values()

获取所有值的数组。

参数: 无
返回: Array - 值的数组

var dict = {"name": "Alice", "age": 25, "city": "Beijing"}
var values = dict.values()
print(values)  // [Alice, 25, Beijing]

// 遍历值
for values to value {
    print("值: " + value)
}

items()

把字典摊平成 Array[DictEntry] —— 每项是 DictEntry{key, value}（按插入序 ✓）。

参数: 无

返回: Array[DictEntry] —— 字段 key / value 编译期已知（native 结构体规格 ✓）； 空字典 ⇒ 空数组（不是 null）。

var d = {"x": 1, "y": 2, "z": 3}
var its = d.items()
print(its.len())          // 3
print(its[0].key)         // "x"（插入序 ✓）
print(its[0].value)       // 1

// 遍历键值对（比 `keys()` + `get()` 两步更直白 ✓）
for its to it {
    print(_str(it.key) + " = " + _str(it.value))
}

⚠ 为什么不是 Array[[k, v]]（每项一个小数组）：位置取值不可读，顺序一漂就静默错位 ✗。 用结构体规格让编译期字段表与运行期定义同源 —— 与 DirEntry（dirs.walk）/ RegexMatch （regexs.find_all）同一套做法 ✓ ⚠ key / value 的静态类型是 any（字典的值类型常常不齐）⇒ 参与运算时显式 _str() / _int() ✓

clear()

清空字典中的所有键值对。

参数: 无
返回: null

var dict = {"a": 1, "b": 2, "c": 3}
dict.clear()
print(dict.len())  // 0
print(dict)        // {}

注意: clear() 会移除所有键值对，但不会释放字典对象本身。清空后可以继续添加新的键值对。

var dict = {"x": 10}
dict.clear()
dict.set("y", 20)
print(dict)  // {y: 20}

copy()

深拷贝：返回一个内容相同、但完全独立的新字典（2026-10-14 新增）。 嵌套的数组 / 字典 / 结构体递归拷贝 ⇒ 改副本不影响原字典，反之亦然 ✓。

参数: 无 返回: 与接收者同型的字典（Dict[string, int].copy() 仍是 Dict[string, int] ✓； 裸 Dict 拷出来还是裸 Dict）；插入序保持 ✓。

var d = {"z": 1, "a": 2}
var c = d.copy()

c.set("b", 3)
print(d.len())      // 2（原字典不受影响）
print(c.len())      // 3
print(c.keys())     // z, a, b（插入序 ✓）

// 嵌套容器也是深拷贝
var src = {"list": [1, 2]}
var dup = src.copy()
var arr = dup.get("list", null) as Array[int]
arr.add(3)
print((src.get("list", []) as Array[int]).len())   // 2（原字典的数组没被改到 ✓）
print(arr.len())                                   // 3

⚠ 代价：深拷贝要递归复制每个值。值里装着大块二进制（如 Array[int] 的信封 —— 每个字节占一个 8 字节的 Value）时并不便宜 ⇒ 只读场景直接传引用即可，别顺手 copy ✓。 ⚠ 口径与 Array.copy() 一致（那也是深拷贝 ✓）。Dict 此前一直没有 copy() （Array / struct 都有）——这次补齐（来源：写 LenoWordBuddy 时的实录 ✓）。 ⚠ 自引用有界（2026-11-16）：Dict[string,any] d; d["self"] = d; d.copy() 此前会 栈溢出崩溃（0xC00000FD）。现在深拷贝有 512 层上限，超限抛 深拷贝失败：嵌套超过 512 层（结构可能存在循环引用）（与 jsons.encode 同口径）。 ⚠ 语义由 assert/test_dict_copy.leno 钉住（长度 / 插入序 / 深拷贝 / 整数键 / 空字典， 五组 ✓）；改实现时先跑它 ✓。

遍历键值对

使用 keys() 和 get() 配合遍历：

var dict = {"name": "Alice", "age": 25, "city": "Beijing"}

// 方式1：遍历键，再获取值
for dict.keys() to key {
    var value = dict.get(key)
    print(key + ": " + value)
}

// 方式2：直接遍历字典（如果语言支持）
// for dict to key, value { ... }

实例方法 vs 模块方法

⚠ 订正（2026-10-14）：本题此前写的是"所有字典方法都支持两种调用方式"并配了一张 dicts.xxx(dict, …) 对照表 —— 实测第二种不成立 ✗：dicts 不是可导入的原生模块 （import dicts ⇒ 「未知的原生模块 'dicts'」），dicts.len(d) 这类写法从来跑不通。 字典的方法只有实例方法一种形式：

实例方法 说明
dict.len() 获取键值对数量
dict.has(key) 检查键是否存在
dict.get(key[, default]) 获取值（类型跟默认值实参走，见上）
dict.set(key, val) 设置键值对
dict.remove(key) 删除键值对，返回被删的值（键不存在 ⇒ null，any 类型）
dict.setdefault(key, default) 键在 ⇒ 返回现值；键不在 ⇒ 写入 default 并返回它
dict.keys() 获取所有键（Array[K]）
dict.values() 获取所有值（Array[V]）
dict.items() 摊平成 Array[DictEntry]（按插入序）
dict.copy() 深拷贝（2026-10-14 新增，见下）
dict.clear() 清空所有键值对

对照：数组有 arrays 模块（arrays.len(arr) / arrays.copy(arr) ✓ 都能用）， 因为它在 native_register_module_method("arrays", …) 里注册过；字典没有对应的注册 ⇒ 没有模块形式。要"动态方法名"只能自己做一层分发（如用 switch 或嵌套字典存闭包 ✓）。

示例代码

示例1：用户信息管理

main() {
    // 创建用户字典（⚠ 空的 `{}` 会被推成 Dict[string, string]，
    //    要装混合类型请显式写 `Dict[string, any]`）
    Dict[string, any] user = {}

    // 添加信息
    user.set("name", "张三")
    user.set("age", 28)
    user.set("email", "zhangsan@example.com")

    print("用户信息:")
    for user.keys() to key {
        print("  " + key + ": " + _str(user.get(key)))
    }

    // 更新年龄
    user.set("age", 29)
    print("更新后年龄: " + _str(user.get("age")))

    // 检查字段
    if user.has("phone") {
        print("电话: " + _str(user.get("phone")))
    } else {
        print("电话未设置")
    }
}

示例2：计数器

main() {
    var words = ["apple", "banana", "apple", "cherry", "banana", "apple"]
    var counter = {}

    // 统计词频
    for words to word {
        if counter.has(word) {
            counter.set(word, counter.get(word) + 1)
        } else {
            counter.set(word, 1)
        }
    }

    print("词频统计:")
    for counter.keys() to word {
        print("  " + word + ": " + counter.get(word))
    }
}

示例3：配置管理

main() {
    // 默认配置（嵌套字典 ⇒ 值类型写 any）
    Dict[string, any] config = {
        "host": "localhost",
        "port": 8080,
        "debug": false,
        "database": {
            "type": "sqlite",
            "name": "app.db"
        }
    }

    // 读取配置
    print("服务器: " + _str(config.get("host")) + ":" + _str(config.get("port")))

    // 修改配置
    config.set("port", 3000)
    config.set("debug", true)

    // 获取嵌套配置
    // 取嵌套字典要**逐层 as**（`get` 返回 any；不 as 的话调不了方法）
    Dict[string, any] db = config.get("database") as Dict[string, any]
    print("数据库类型: " + _str(db.get("type")))

    print("最终配置:")
    for config.keys() to key {
        var value = config.get(key)
        if type(value) == "dict" {
            print("  " + key + ": {...}")
        } else {
            print("  " + key + ": " + _str(value))
        }
    }
}

示例4：缓存实现

// 简单的内存缓存
Dict[string, any] cache = {}
Dict[string, int] cache_stats = {"hits": 0, "misses": 0}

func cache_get(string key): any {
    if cache.has(key) {
        cache_stats.set("hits", cache_stats.get("hits") + 1)
        return cache.get(key)
    }
    cache_stats.set("misses", cache_stats.get("misses") + 1)
    return null
}

func cache_set(string key, any value): void {
    cache.set(key, value)
}

func cache_remove(string key): void {
    cache.remove(key)
}

func cache_clear(): void {
    for cache.keys() to key {
        cache.remove(key)
    }
}

main() {
    // 模拟缓存使用
    cache_set("user:1", {"name": "Alice", "age": 25})
    cache_set("user:2", {"name": "Bob", "age": 30})

    // 命中
    var user1 = cache_get("user:1")
    print("获取 user:1 = " + _str(user1))

    // 命中
    var user1_again = cache_get("user:1")

    // 未命中
    var user3 = cache_get("user:3")
    print("获取 user:3 = " + _str(user3))

    print("缓存统计:")
    print("  命中: " + _str(cache_stats.get("hits")))
    print("  未命中: " + _str(cache_stats.get("misses")))
    print("  缓存大小: " + _str(cache.len()))
}

示例5：与数组结合使用

main() {
    // 数组嵌套字典
    var users = [
        {"id": 1, "name": "Alice", "active": true},
        {"id": 2, "name": "Bob", "active": false},
        {"id": 3, "name": "Charlie", "active": true}
    ]

    // 过滤活跃用户
    var active_users = []
    for users to user {
        if user.get("active") {
            active_users.add(user)
        }
    }

    print("活跃用户:")
    for active_users to user {
        print("  - " + user.get("name"))
    }

    // 按 ID 索引
    Dict[string, any] user_by_id = {}
    for users to user {
        user_by_id.set(_str(user.get("id")), user)
    }

    print("通过 ID 查找:")
    Dict[string, any] hit = user_by_id.get("2") as Dict[string, any]
    print("  ID=2: " + _str(hit.get("name")))
}

示例6：JSON 数据处理

import jsons

main() {
    // JSON 字符串
    var json_str = '{"name": "Product", "price": 99.99, "tags": ["new", "hot"]}'

    // 解析为字典（`decode` 返回 any ⇒ 要 as 成 Dict 才能调方法）
    Dict[string, any] data = jsons.decode(json_str) as Dict[string, any]

    print("产品信息:")
    print("  名称: " + _str(data.get("name")))
    print("  价格: " + _str(data.get("price")))

    // 修改数据
    data.set("price", 79.99)
    data.set("stock", 100)

    // 转回 JSON（编码叫 `encode`，没有 `stringify`）
    var new_json = jsons.encode(data)
    print("更新后 JSON: " + _str(new_json))
}

哈希冲突

  • 使用链地址法或开放寻址法处理冲突
  • 负载因子超过阈值时自动扩容
  • 扩容时重新哈希所有元素

注意事项

1. 键类型限制

字典的键必须是字符串：

var dict = {}

// 正确
dict["key"] = "value"
dict.set("name", "Alice")

// 错误：键必须是字符串
// dict[123] = "value"  // 错误
// dict.set(123, "value")  // 错误

// 如果需要数字键，转换为字符串
dict["123"] = "value"

2. 键的唯一性

字典中键是唯一的，重复设置会覆盖：

var dict = {}
dict.set("key", "value1")
dict.set("key", "value2")
print(dict.get("key"))  // value2

3. 值类型无限制

值可以是任意类型：

var dict = {}
dict["number"] = 42
dict["string"] = "hello"
dict["bool"] = true
dict["null"] = null
dict["array"] = [1, 2, 3]
dict["dict"] = {"a": 1}

4. 遍历顺序

字典遍历顺序不保证与插入顺序一致：

var dict = {}
dict["a"] = 1
dict["b"] = 2
dict["c"] = 3

// 遍历顺序可能是 a,b,c 也可能是其他顺序
for dict.keys() to key {
    print(key)
}

5. 空值处理

  • get() 不存在的键返回 null
  • remove() 不存在的键静默处理（不报错），返回 null；键存在时返回被删掉的值 ⇒ 值与返回值都可能为 null，要区分"删掉了空值"和"键本来就没有"请先 has()
  • has() 可以区分"不存在"和"值为 null"
var dict = {"a": null}
print(dict.has("a"))      // true（键存在，值为 null）
print(dict.get("a"))      // null
print(dict.has("b"))      // false（键不存在）
print(dict.get("b"))      // null（键不存在）

最佳实践

  1. 使用 [] 语法访问：代码更简洁
   // 推荐
   dict["key"] = value
   var val = dict["key"]

   // 不推荐（除非需要动态键名）
   dict.set("key", value)
   var val = dict.get("key")
  1. 检查键存在性后再操作：
   if dict.has("key") {
       var value = dict["key"]
       // 处理 value
   }
  1. 使用 keys() 和 values() 遍历：
   // 遍历键值对
   for dict.keys() to key {
       var value = dict[key]
       print(key + ": " + value)
   }
  1. 嵌套字典安全访问：
   // 检查每一层
   if dict.has("user") {
       var user = dict["user"]
       if user.has("name") {
           print(user["name"])
       }
   }
  1. 避免在遍历时修改字典：
   // 错误：遍历时修改可能导致问题
   for dict.keys() to key {
       dict.remove(key)  // 危险！
   }

   // 正确：先收集要删除的键
   var to_remove = []
   for dict.keys() to key {
       if should_remove(key) {
           to_remove.add(key)
       }
   }
   for to_remove to key {
       dict.remove(key)
   }
