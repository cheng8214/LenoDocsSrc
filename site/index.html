Leno 是什么

一门自研 VM 上的工程脚本语言：兼具静态类型检查与运行时灵活性， 适合桌面应用、工具链、系统封装与脚本内核开发。既能写业务层，也能用 FFI / cstruct / Ptr 下探到原生内存。

类型收窄 · 可空类型 · 泛型 struct / enum / face 模块系统 + 19 个标准模块 线程并发 + async / await FFI · cstruct · Ptr 原生内存 int48 内联 · 自研字节码 VM

从零入门 → 语法速查 → 模块 API →

main() {
    print("Hello, Leno!")
}
